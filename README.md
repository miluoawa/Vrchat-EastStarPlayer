# 极星播放器 · Eaststar Player

**面向 VRChat 世界的中文多人同步视频播放器**

版本：v0.3.13 ｜ 作者：miluo

极星播放器基于 Unity、VRChat Worlds SDK 和 UdonSharp 开发，提供独立主屏、世界空间控制台、多屏同步、共享播放列表以及 PC / VR 个人悬浮观影体验。

## 功能特性

- **多人同步播放**：共享播放列表，最多支持 20 条待播放视频，播放结束后自动播放下一条，支持后加入玩家同步。
- **播放列表**：显示视频地址、添加者及尝试探测的视频时长；探测失败时显示未知。
- **权限管理**：当前视频添加者可以调整进度；实例 Master 可以跳过视频及停止并清空列表。
- **本地观影控制**：支持本地音量、本地暂停、恢复播放和重新同步，不影响其他玩家的播放进度。
- **主副屏同步**：通过编号匹配，一台主屏可连接多个无独立音源的副屏，共享视频画面。
- **副屏表面吸附**：在 Unity Inspector 中开启吸附面后，可在 Scene 视图拖动副屏贴合附近表面。
- **个人悬浮屏**：PC 和 VR 均支持召唤、拾取和移动仅自己可见的悬浮屏，共享主屏画面与音源。
- **悬浮屏内嵌控制台**：支持添加视频、查看队列、音量与进度控制等操作，并提供返回播放屏幕按钮。
- **紧凑中文 UI**：深色界面、细轨道、圆形滑块、透明播放/暂停图标与自动淡出的设置图标。

## 版本选择

| 功能 | 普通直连版 | Kipfel 解析版 |
| --- | --- | --- |
| 直接提交可播放 URL | 支持 | 可将解析前缀清空后使用 |
| 内置解析前缀 | 无 | `https://api.kipfel.link/v1/vrc?url=` |
| 自定义解析前缀 | 支持 | 支持 |
| 其他播放器功能 | 一致 | 一致 |

两个版本的资源 GUID 相同，请只安装其中一个。

## 环境要求

- 使用 VCC 或 ALCOM 管理的 VRChat Worlds 项目。
- VRChat Worlds SDK 3.8.1 或更高版本，以及 UdonSharp。
- SDK 自带 VideoPlayers 示例预制件（用于生成控制台的 Canvas）。
- 支持简体中文的 Unity 动态字体，需要自行导入。

## 安装步骤

1. 保存场景并备份项目；若已安装旧版极星播放器，先备份并移除旧版场景实例及重复脚本。
2. 将 ZIP 解压到项目外，把 `极星播放器` 文件夹和同级的 `极星播放器.meta` 复制到 Unity 项目的 `Assets` 目录。
3. 打开 Unity，等待 C# 与 UdonSharp 编译完成，确认 Console 无红色错误。
4. 在 Project 窗口选中支持中文的动态字体，执行 `Tools → Eaststar Player → 1 - Generate Prefabs`。如果首次生成时提示创建 Udon 程序资源，等待编译完成后再执行一次。
5. 执行 `2 - Add and Link Both Prefabs`，将主屏和控制台加入场景，再调整位置、旋转和缩放。
6. 如需副屏，执行 `4 - Add Secondary Display` 或拖入副屏预制件，设置编号后执行 `3 - Link Screens by ID`。
7. 保存场景，通过 VRChat SDK 的 Build & Test 测试。

> 请勿将整个 ZIP 外层解压目录再次拖入 Assets，也不要同时保留同品牌的多个版本，以免发生类名和 GUID 冲突。

### 预制件

生成后位于 `Assets/极星播放器/Prefabs/`：

| 预制件 | 用途 |
| --- | --- |
| `Eaststar_Display.prefab` | 主屏幕，负责视频播放、音频及网络同步 |
| `Eaststar_Console.prefab` | 独立世界空间控制台 |
| `Eaststar_SecondaryDisplay.prefab` | 可选副屏，只显示画面，无独立音源 |

主屏与控制台均为必需组件；副屏按需添加。个人悬浮屏由链接工具及世界构建回调创建，无需额外拖入预制件。

## 视频播放

### 普通直连版

将可播放的视频 URL 粘贴到控制台输入框，点击「添加到列表」。空闲时开始播放，已有视频播放时加入等待队列。

### Kipfel 解析版

**授权说明：极星播放器集成 Kipfel 视频解析服务已获得 Kipfel 作者海洛的授权。感谢海洛对本项目的支持。**

控制台会预填以下解析前缀：

```text
https://api.kipfel.link/v1/vrc?url=
```

保留前缀，在英文等号后粘贴原始视频网址，例如：

```text
https://api.kipfel.link/v1/vrc?url=https://www.bilibili.com/video/BVxxxxxxxxxx
```

由于 VRChat SDK 对运行时构造 `VRCUrl` 的限制，不能只输入原始 B 站链接并由 Udon 任意拼接解析地址。添加视频后，输入框会恢复默认前缀。

非受信任域名可能需要玩家开启 VRChat 的「Allow Untrusted URLs」。Kipfel 为外部第三方服务，其可用性、解析结果及视频格式不由极星播放器保证；并非所有网站或视频都可以播放。

## 玩家操作与权限

| 操作 | 普通玩家 | 当前视频添加者 | 实例 Master |
| --- | :---: | :---: | :---: |
| 添加视频、查看队列 | ✓ | ✓ | ✓ |
| 本地暂停、音量、重新同步 | ✓ | ✓ | ✓ |
| 调整当前视频进度 | — | ✓ | 仅本人添加的视频 |
| 跳过视频、停止并清空 | — | — | ✓ |

实例 Master 由 VRChat 管理，原 Master 离开后会移交；它并不等同于实例创建者的永久权限。

本地暂停会同时暂停自己的画面和声音，恢复时追上房间当前进度。直播及未知时长的视频暂不支持本地暂停。

## 个人悬浮屏

| 操作 | PC | VR |
| --- | --- | --- |
| 召唤 / 关闭 | TAB | 同一侧扳机连续按三次 |
| 拾取 / 放下 | VRChat 原生拾取操作 | VRChat 原生抓取操作 |

悬浮屏在玩家面前生成，放下后停留在世界空间，不跟随头部移动。仅本地玩家可见；没有额外视频播放器或音源。

- 点击画面：显示播放/暂停图标及左上角设置图标（待机时也可打开设置）。
- 播放状态：暂停图标显示 3 秒后淡出；暂停状态：播放图标持续显示。
- 设置图标：无操作 3 秒后开始淡出，点击可打开个人控制台。
- 返回播放屏幕：点击控制台内的返回按钮。
- 移动屏幕：拾取底部标有「抓握区域」的握把。

## 主副屏配对与吸附

在主屏 Inspector 中设置「副屏编号」，在副屏 Inspector 中设置「主屏编号」。两者编号相同即为同一组。不同主屏应使用不同的正整数编号。设置完成后执行菜单 `3 - Link Screens by ID`。

副屏可在 Inspector 中启用以下编辑器设置：

| 参数 | 默认值 |
| --- | --- |
| 吸附面 | 关闭 |
| 吸附距离 | 0.35 m |
| 离面间隙 | 0.003 m |
| 自动贴合朝向 | 开启 |

开启后，在 Scene 视图移动副屏即可尝试贴合附近的模型表面。复杂曲面可能需要手动微调。吸附仅用于编辑器摆放，不参与游戏运行时播放逻辑。

| 2 - Add and Link Both Prefabs | 添加并连接主屏与控制台 |

## 技术说明

极星播放器源自猫咖播放器 v0.3.13 的品牌分支，保留播放、队列、权限和同步逻辑，并使用独立的类名及资源 GUID。视频解码使用 SDK 原生 `VRCUnityVideoPlayer`，控制台生成时复用 SDK VideoPlayers 示例的 Canvas 结构，不等同于完全独立的视频解码引擎。

安装包包含 C# 源码、图片和 Unity `.meta` 文件，不包含 SDK、中文字体或预先编译好的预制件。同一场景不建议同时使用猫咖与极星主屏，以免个人屏幕快捷键同时触发。

## 常见问题

- **UdonSharp 无法获取 C# 类**：检查是否存在重复安装，并优先处理 Console 中最早的 `error CSxxxx`。
- **控制台中文显示方块**：导入支持简体中文的动态字体后重新生成预制件。
- **副屏不显示视频**：检查编号是否一致，并重新执行菜单 3。
- **视频无法播放**：确认链接格式、解析服务可用性和 VRChat URL 信任设置。
